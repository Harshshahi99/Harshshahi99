# 💫 About Me

I'm an **Offensive Security Engineer and Security Consultant at Deloitte** with **3+ years of experience** in cybersecurity, focused on **penetration testing, offensive security, cloud security, adversary simulation, and vulnerability research**.

My experience covers a broad offensive-security landscape including **Web & API Security, Cloud, Access Control, Device Security, Thick Client, Active Directory, Network Segmentation, Infrastructure, Phishing Simulation, OSINT, Mobile, IoT, and LLM Security**.

I approach security from an **attacker's perspective** — combining reconnaissance, enumeration, manual testing, exploitation, attack-path analysis, validation, and remediation.

### 🔐 Responsible Disclosure

I actively participate in **responsible disclosure**, identifying security issues in internet-facing applications and platforms and working with organizations to responsibly report, validate, and remediate security weaknesses.

### 🤖 Currently Exploring

I'm exploring **AI-led penetration testing and multi-agent security automation**, with a focus on using AI to assist with:

`Reconnaissance` · `Enumeration` · `Attack-Path Analysis` · `Security Testing` · `Validation` · `Reporting`

The goal is to build intelligent workflows that automate repetitive stages of the penetration-testing lifecycle while keeping **human-led security validation and attacker reasoning** at the core.
